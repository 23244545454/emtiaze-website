# Modern Diesel Industry Premium Design Update

## Vision
Transform the Emtiaze Company website into a **modern, premium petroleum industry design** that communicates professionalism, reliability, and cutting-edge logistics expertise.

---

## Color Palette Transformation

### Old Theme
- Primary: `#ff6b35` (bright orange)
- Secondary: `#ff9500` (standard orange)
- Background: `#fff8f3` (warm beige)

### New Theme - Diesel Industry Premium
- **Primary**: `#ff7a3d` (premium warm orange - modern & sophisticated)
- **Primary Hover**: `#ff6b2b` (deeper industrial orange)
- **Secondary**: `#ffb347` (golden accent - premium feel)
- **Secondary Hover**: `#ff9f2a` (warm gold)
- **Accent Light**: `#ffc368` (bright highlight)
- **Accent Dark**: `#cc5200` (dark petroleum tone)

### Background Improvements
- **Old**: Warm beige `#fff8f3`
- **New**: Professional cool gray `#f7f8fa` (modern tech/industrial aesthetic)
- **Gradient**: More sophisticated cool-to-gray flow for diesel industry feel

### Text Colors
- **Primary**: `#0f1419` (deeper, more professional dark)
- **Secondary**: `#4a5568` (warmer gray - better readability)
- **Light**: `#8a92a3` (professional neutral)

## Component Enhancements

### 1. Hero Section
**Before**: Warm, light background
**After**: Professional cool-gray gradient background with premium appeal

**Typography**:
- Title now uses premium gradient: `#ff7a3d` → `#ff9500` → `#ffb347`
- Font weight increased to 900 (extra bold for impact)
- Font size increased: `2.5-4.5rem` → `2.8-5rem` (more presence)
- Line height tighter: 1.1 → 1.05 (stronger visual impact)

**Floating Shapes**:
- Updated gradients to match new color theme
- Enhanced backdrop blur: 2px → 3px (more sophisticated effect)
- Improved shadow depth with new color palette

### 2. Call-to-Action Button
**Style**: Modern, pill-shaped design
- Border radius: `var(--radius-lg)` → `50px` (fully rounded)
- Padding: More generous `18px 50px`
- Shadow: Enhanced depth `0 12px 35px` (premium feel)
- Gradient: Premium orange to deeper orange
- Hover: Lifts higher `-8px` (more dramatic interaction)
- Text letter-spacing: Increased to `1.2px` (premium typography)

### 3. Counter Numbers (Stats)
- Font size: `3.5rem` → `3.8rem` (more prominent)
- Font weight: `800` → `900` (heavier impact)
- Gradient: Updated to `#ff7a3d` → `#ffb347`

### 4. Feature Icons
- Size: `3.5rem` → `3.8rem` (bigger visual impact)
- Gradient: Premium orange tones for industry identity

### 5. Process Step Icons
- Size: `3rem` → `3.2rem`
- Gradient colors updated for consistency

### 6. Cards (Service, Feature, Project, Step)
- Accent colors updated across all hover states
- Shadow colors now use premium orange `rgba(255, 122, 61, ...)`
- Border colors adjusted for new theme consistency
